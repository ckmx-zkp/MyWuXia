# 失落港区

独立 HTML 第一人称搜打撤原型。基于用户提供的《几猫国产3A大作_V1.html》改作，保留其内嵌 Three.js、港区场景、实时光影、雨水、步枪、机械猎犬、机械海鸥、中继目标与撤离艇。不是商业 3A 成品。未替换《江湖长夜》入口。

## 运行

双击 `public/salvage-v1.html`，或通过站点 `/salvage-v1.html` 访问。不需要 CDN、安装依赖或联网下载资源。需要支持 WebGL2 的现代桌面浏览器。集成显卡可在设置中降低画质。鼠标锁定受限时沿用参考文件的拖动视角模式。

WASD 移动，鼠标转向，左键射击，右键瞄准，R 换弹，Space 跳跃，Shift 冲刺，C 下蹲，F 近战，长按 E 切断中继，长按 G 搜索近旁物资箱 / 残骸，B 背包，H 急救，Esc / P 暂停。触屏额外提供搜索、背包和急救按钮。

## 本次增加

- 起点、中继周边、撤离点的可搜索物资箱，及击毁机器人后的残骸回收箱。生成点检查可行走与视线。
- 5 类物品、品质、价值和 20 kg 容量。搜索需 1.1 秒，远离或中断会重置。
- 2 个急救包，每个恢复 45 点生命，6 秒冷却。
- 背包界面打开时暂停行动。成功撤离才结算入库，阵亡丢失当局战利品，重新部署清理场景箱体。
- 仓库通过独立版本键 `salvage-port-v1` 保存，避免干扰武侠存档；存储被浏览器拒绝时显示提示。

## 维护

新增系统源文件是 `scripts/salvage-extension.js`。修改后执行 `node scripts/build-salvage.mjs`，将代码内嵌到独立 HTML。基础游戏来自用户参考文件，其已有代码以原始内嵌形式保留。画面采用实时三维模型，未把概念图作为可玩场景或界面贴图。

发布执行 `npm run deploy -- --asset=salvage-v1.html`，先运行新增回归、全项目测试和构建，再复制线上现有发布目录，只替换此 HTML，通过原子切换上线并保留上一版。不会发布当前工作区其他尚未完成的页面和 API 修改。

## 验证边界

仓库和结算测试需覆盖成功、阵亡和重试；完整真人枪战平衡与不同显卡性能仍需要持续试玩。设计概念仅用于光影和界面方向，实际浏览器画面以实时渲染为准。
