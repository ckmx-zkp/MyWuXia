# 支线因果重构：P0 / P1 实装边界

更新：2026-09-08。本章是本批因果重构的当前依据，优先于 02、11、12 及开发看板中的历史计划。此处 P0/P1 专指支线因果重构，不表示整个放置 RPG 路线图已经完成。

## 目标与取舍

任务必须回答“为什么现在发生、谁需要它、完成或放弃后什么会不同”。不靠增加任务数量延长流程。主线揭示处境，支线建立证据或退路，主线决定是否采用，后续处理留存的人与关系。可拒绝、可错过；不要求清空所有支线才能推进主线。

73 个旧内容包逐项归类：7 个保留新接入口，66 个停止新接；不是删除旧存档内容。逐包主线来源、成功事实和处置原因见 [14-pack-audit.md](14-pack-audit.md)。保留包也须先经历相关主线，并且公共目标尚未解决。已经接取的旧包可继续原流程。

## 框架与存档

- 内容：`story-arcs.js` 定义人物动机与改线结果；`causal-events.js` 生成每线准备、后续、过期善后三种契约（共 24 个）；`pack-policy.js` 定义旧包真实成功事实。
- 导演：`story-director.js` 只决定机会是否适用及已接任务是否过期。保留来源、条件、费用、结算，不让模型临时发明任务。
- 图：`story-graph.js` 在加载时将原八树编译为稳定节点/选项 ID 和 next/failNext；原节点顺序及旧选项索引不变，新增选项追加。旧节点继续保持原有主动交手、失手追兵和软失败。
- 结算：`encounter-settlement.js` 按显式后继推进，写选择、世界效果、不同结局与 NPC 阶段；已完成节点不能重复领奖。
- 条件/效果：继续使用 `world-rules.js` 命名空间，不隐式合并 world flag、事件 facts、NPC 和主线进度。
- 存档：v8，接受 v1–v7。保留旧数字游标、选择索引、行动、战斗和手动槽位；迁移补齐已完成主线的完成标志，不补发奖励。新的 startedAt 为世界时间，不用墙钟补算机会窗口。
- 文案：LLM 仍只覆盖 SIDE_EVENTS 的许可文字；上下文带世界标志和 NPC 状态。事实值变化、模板变化会使缓存失效；返回仍经 mergeOverlay 校验。没有声称原八树全部接入 LLM 或自治 Agent。

## 机会与善后

准备入口只在已接触人物、尚未越过关键抉择时出现。接取后有 900 世界息窗口；离线不消耗。推进主线越过抉择同样会结束准备窗口。进行战斗/行动时暂缓协调，结束后再处理，避免损坏续接。

玩家可直接拒绝、说明办不到或主动放弃窗口。拒绝仍可走原路线；过期产生善后机会，付十两可帮助留下的人，但绝不重新授予 ready 或倒转主线。主线结束后的来信允许兑现改线承诺、补办安置、只交消息三种收尾。后两者不伪称采用了原本未走过的新结局。

## 验证与未包含范围

本批 npm test 的 96 项测试通过，npm run build 的内容审计与生产构建通过。构建必须运行 73 包政策审计、8 树后继检查、条件/效果与事实来源校验。自动回归覆盖八条新分支、双证据限制、交易和护送变化、旧包兼容、窗口过期、保存恢复及结局不重复结算。八树测试在关键阶段设置合法游标以隔离结算验证，不等于八部剧情逐字人工通关。当前主包约 749 KB（gzip 239 KB），仍有旧包静态载入导致的体积警告，未将此归作已优化。

浏览器已从新角色实际走通扬州救治、付费安排、选择后埠撤出，并确认跨区北行来信的路线入口。无本地 API 时使用固定文案回退；线上健康检查不等于长周期玩家平衡测试。

本批采用“原八树的运行时图适配”，没有把所有原著节点重新创作，也没有废弃数字游标。人物面板是由已发生的剧情事实推导阶段、地点和关系，不是独立于玩家运行的完整 NPC 日程模拟。24 个事件共享契约骨架，以便审计；后续应继续删减无独立结果的重复委托。

P2 保留：跨章节长期势力演化、NPC 自主日程与多轮关系网络、更多区别化后续内容、全地图生活系统、批量玩家路线/经济平衡测试，以及旧大包进一步动态拆载。

## 原作与新增内容来源边界

人物关系及旧事起点取自仓库 `src/content/quests/<ID>.js` 的现有改编。尝试访问维基百科时返回 403，搜索结果未提供可信的具体情节证据，因此没有把网络摘要当成核实依据，也不列虚假参考链接。

渡簿、药车、接济与海船连接是本项目原创的跨书改编，不宣称金庸原文已有这些跨线因果。新增路线刻意不把行踪当作真凶证明、不把安排会面等同消除旧怨、不把善后等同死人复活。后续有可靠文本出处时，再逐条补充原著章节与改编差异。
