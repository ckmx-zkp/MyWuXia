# 剧本与事件文案工程规范（文案框架与对话标准）

本文件定义了《江湖长夜》所有任务、事件、NPC对话与环境交互的统一文案填充框架。所有编写给程序解析的剧情数据必须严格按照此框架交付。

---

## 一、文案设计铁律与文风标准

1. **客观白描与金古笔力**：
   - 避免网络玄幻/现代网文腔调（严禁“叮”、“宿主”、“暴击伤害9999”等术语入对话）。
   - 环境交代采用凝练白描，动静结合；对话符合市井、江湖各阶层身份（士大夫文雅带机锋，绿林豪客粗粝重诺，佛道中人空灵警醒）。
2. **拒绝主角替身**：
   - 玩家是独立行动者，不自动继承原著主角身份与经历。原著人物保有自身动机，但其命运与重大事件可以被玩家行动改变；跨书人物在同一世界互动，条件与后果必须落入统一状态（详见 `10-changing-fates.md`）。
3. **生活化与生态感**：
   - 所有任务不是凭空出现，必须能从“客栈传闻”、“告示牌通缉”、“茶摊闲话”或“NPC随口抱怨”中捕捉到动机。
4. **选择与软失败文本支撑**：
   - 任何选项不得是“选A立刻成功，选B毫无意义”。每个分支选项都必须配齐对应的情景反馈、挫折描述（软失败）及长线江湖后果。

## 三、对话系统文案分层规范

为了消除任务的孤立感，对话文本细分为四级：

### 1. 境遇层（Greeting & Ambiance）
NPC 依据世界当前状态、天气、玩家声望展现第一句话：
* **门派冷淡/低声望**：“阁下脚步虚浮，衣上沾着外乡泥水，不知来我山门有何贵干？”
* **名动江湖/高侠义**：“原来是近日平息汉水风波的大侠，快请上座！不知此番到访有何指教？”

### 2. 动机层（Plot Core）
NPC 交代困境或冲突，绝不直接发任务指令，而是陈述客观危机：
* *例*：“神农帮把这无量后山围得水泄不通，连采药的山道都撒了剧毒瘴气，庄上的妇孺已经断粮两日……”（由此自然引出‘探山破围’的意向）。

### 3. 交涉与检定层（Branch & Skill Checks）
提供差异化的响应文本，包含：
* **武学与属性检定**：【臂力】震慑、【身法】截击、【内力】破毒、【悟性】拆解武功、【福缘】洞察机关。
* **江湖身份加成**：拥有捕快令牌、名门通引、绿林信物时，解锁特殊对白。

### 4. 余波与江湖传闻（Echo & Rumors）
任务结算后，周围环境 NPC 必须产生回响：
* 客栈的小二、茶摊的老板会更新传闻台词；
* 原著人物状态机推进（段誉从“无量观礼”迁跃为“万劫受困”）。

