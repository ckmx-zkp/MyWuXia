# 可改变的命运与跨书江湖

## 2026-09-08 因果接入

三帮仍保留原十节点状态机；争执阶段新增 witness_sheltered + medicine_wudang 双条件入口，进入会审而非直接结盟。杏子林改线须活证人准备与燕子坞渡簿，结果影响护送、道路与药价。角色变化的展示与兼容边界见 [14-story-causality.md](14-story-causality.md)。

用户已明确：原著只定义起点，玩家必须能改变人物剧情；不同作品人物可以同场并产生关系。此要求优先于旧文档中“只改变局部结果”“保护核心命运事件”“分支必须汇合”的限制。

## 世界设定

- 北丐帮帮主乔峰、东丐帮帮主洪七公、西丐帮帮主史火龙，三帮独立存在。
- 不以原著年代排斥共存，使用统一游戏世界时间。其他地域与三帮辖区暂不擅自确定。
- 交互应由利益、义理、情报、武学传承和政治压力驱动，不以客串对白代替关系变化。

## 事件规则

1. 玩家仍是独立角色，不自动继承原著主角身份、经历和绝学。
2. 命运有多个有效后继状态：救援可以真正避免死亡，调查可以改变误判，结盟可以改变帮主与势力关系；世界不自动纠回原著。
3. 每个重大分支写清触发条件、机会窗口、成功/软失败回响，以及受影响的人物、设施、任务和势力。
4. 跨书互动共享事实：某帮获得证据后，另两帮的态度与行动应读取同一世界标记；不能各演互相矛盾的版本。
5. 后续任务须为已死亡、失踪、离任或结仇的人物提供替代入口，避免断档。

## 已实现试点：三帮失粮案

完成无锡 WX-01《杏子林变局》后，三帮失粮案进入命运面板。事件使用统一世界时间，关键阶段有机会窗口；挂机、旅行和行动都会使世界时间前进。

```text
三帮争端
├─ 赴荆襄查证 ─ 保护证人 ─ 三帮会审 ─ 三帮同盟 ─ 联运粮路
│              └ 抄录账目 ─ 三帮会审 ─ 停争未盟 ─ 民间赈济
├─ 直接调停 ───────── 三帮会审 ─ 停争未盟
├─ 偏袒北帮 ───────── 三路封粮 ─ 补偿重查 / 江湖分途
└─ 机会窗口超时 ───── 三路封粮 ─ 补偿重查 / 江湖分途
```

联盟要求同时取得账簿和活着到场的证人；只有纸证可促成停争，不能直接结盟。结果会更新三帮关系、三位帮主状态、世界标记、声望和后续跨区事件。已经结算的节点写入历史，不能重复领取奖励。

本试点已实现事件图、条件门槛、机会窗口、跨区节点、NPC 状态和势力关系存档恢复。其余原著任务树仍按现有线性结构运行，后续逐棵迁移。
