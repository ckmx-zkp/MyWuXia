# 城市持续玩法与 P0-A/B/C 交付

## 问题与处理

过去四项历练呈现为城市的全部内容，原著剧情藏在翻页中，成长与护药又位于另一页面。现在四项历练定位为「初识当地」，当地首页持续列出人物线、进行中的支线、下一地点与生活差事。

- 当前区域人物线直接打开正确的未完成节点，无需先清四项任务；完成的树退出待办。
- 未到本区的已接支线给出邻接区域路线；本区房间任务给出逐步行走按钮，不越过出口。
- 远方线索只指向实装剧情。它们是独立经历的推荐，不声称前一棵树必然引发另一棵树。
- 杏子林完成后原有三帮命运继续提供入口。
- 无人物树的区域仍保留四项初识、持续差事、护送、补给设施与远方线索；尚未新增每区长篇主线。

## 首条回访链：药路回信

内容版本 1，原创连接事件，无外部代码/对白复制。

护药完成 → 回春堂接信 → 江南启程荆襄 → 武当山门问讯 → 回春堂交回口信。

四个节点均有情境、对白、选择、回响和传闻；来回允许中途做其他事。首次交信潜能十五，首次回程交付三份青叶草与潜能十五。药师的固定对白随完成事实变化。旧护药的五两收购价、华山教学引荐保留。

此链提供真实的离城与返城动机；制药、北上药车大战或新的武当高阶剧情没有以空入口占位。

## 规则内容写法

- 条件：`{ all: [{ ref: 'fact:medicine_complete', op: 'eq', value: true }, ...] }`，支持 any/not。
- 显隐：`visibleWhen`；可选性：`requires` 和 `cost`。不可选显示原因。
- 白描变化：`variants: [{ priority, when, dialogues }]`，优先级高者优先，无匹配回到默认对白。
- 效果：资源 add、事实/NPC set、关系增减、已学武学教学上限提升、旧任务完成标记。旧 P0 效果对象通过适配转入同一执行器。
- 事件：room 或 zone、start/nodes、next/failNext/retreatNext、terminal；战斗 pending 记录 eventId/nodeId/choiceId。
- 持久化：节点、内容版本、选择结果与效果凭据；日志截断不删除效果凭据。成本重复尝试仍扣，节点选项效果不重复发。

## 时间与兼容

现实计时只用于生活修炼收益、战报推进与真正的内容加载。旅行、旧一次性任务不再现实空等；反复点差事没有即时奖励。

v7 接受 v1-v6。旧未完成行动保留到加载命令，一次性续接，之后立即保存已抵达或交手上下文。旧考核战斗以适配器回到统一事件；旧已完成江南密信不会重新出现或重复领奖。

## 后续扩展

P1 逐棵迁移原著剧情，补任务后果改变人物位置、道路与教学的实际内容；优先扩展已有线索可抵达的地点。随后按城市增加人物后续与生活事件，避免为了数量新增互不关联的任务框。
