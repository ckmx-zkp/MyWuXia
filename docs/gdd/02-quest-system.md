# 任务系统 GDD

## 任务系统核心

> 整个世界是沙盒非线性的。现有任务树暂保持线性兼容，新剧情采用可改变人物命运的事件分支，原著结局不是强制终点（详见 `10-changing-fates.md`）。

玩家可以同时在同一区域接触不同作品的任务树。例如大理能同时存在段誉线、一灯线、武三通线及云贵五仙教事件；玩家自行决定介入顺序。

## 四层内容

| 层级 | 时长 | 作用 |
|---|---:|---|
| 天下大主线 | 数十小时 | 国家、城池、战争的世界状态变化 |
| 区域大主线 | 5–15 小时 | 改变区域势力和门派关系 |
| 人物小主线 | 1–5 小时 | 改变人物关系与局部结果 |
| 支线/练级 | 5–60 分钟 | 属性、金钱、关系、线索与生活体验 |

## 任务树设计规则

- 旧主干节点线性推进；新分支允许改变人物存亡、阵营及事件走向，不强制汇合到原著结局。通过共享世界标记与条件入口控制内容规模。
- 主线失败使用“扣血、损钱、延迟、NPC 协助、额外敌人”等软失败，不得永久断线。
- 原著事件按世界时间继续；玩家没接任务也会发生，NPC 会切换到新的命运阶段。
- 高危人物必须有境界/危险警告。低等级玩家应有旁观、逃跑、救援、潜行等解法。
- 任务奖励只使用：钱、药、阅历、武学经验、好感、声望/侠义；负面为掉血、中毒、掉钱、掉声望、掉好感、装备损耗或危险标记。

## 城市内容配额

一级核心城市目标：3 条区域主线（每条 6–12 节点）、5 条人物树（每条 3–8 节点）、10 条普通支线（每条 1–3 节点）、5 条循环任务与动态 NPC 遭遇。

## 动态 NPC

NPC 需要 `命运阶段`、`下一事件`、`世界时间条件`。例如乔峰可经历：丐帮帮主 → 杏子林事件 → 身世调查 → 聚贤庄 → 雁门关 → 辽国南院大王；每一阶段的称谓、区域、关系和任务均不同。
