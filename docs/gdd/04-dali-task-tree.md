# 大理任务树样板

## 区域主线总顺序

```text
无量山风波 → 木婉清 → 四大恶人 → 万劫谷 → 大理世子 → 天龙寺 → 鸠摩智 → 六脉神剑
```

该顺序仅约束“大理天龙主线树”内部；玩家可同时游玩南帝旧踪、武三通旧怨或其它区域任务。

## DL-01：无量山风波

| 节点 | 内容 | 关键玩法 | 软失败 |
|---|---|---|---|
| Q01 剑湖观剑 | 观看东西二宗比武 | 观察；多嘴可触发低级比武 | 被驱赶或 HP -20%，仍继续 |
| Q02 梁上少女 | 段誉与钟灵冲突 | 选择帮助、沉默或偏向门派 | 仅改变初始好感 |
| Q03 闪电貂 | 毒兽伤人 | 即时抓貂支线 | 中貂毒、HP 持续下降 |
| Q04 神农围山 | 三条撤离路线 | 守山、救伤员或撤离 | 经验/侠义差异，汇合 Q05 |
| Q05 钟灵失踪 | 采集解毒草 | 采集和药理 | 轻毒，仍可潜入 |
| Q06 夜入药圃 | 神农帮营地 | 潜行或战斗 | 轻功低时战斗神农弟子 ×3 |
| Q07 万劫谷 | 救出钟灵 | 关系与地图传闻 | 开放万劫谷 |

完成奖励：钟灵好感 +10、银两、解毒丸、万劫谷传闻。

## DL-02：南帝旧踪

链条：铁掌之伤 → 皇帝去了哪里 → 渔樵耕读四关 → 南帝 → 一阳救人 → 旧宫往事。

玩家负责找郎中、调查线索、完成渔/樵/耕/读属性挑战与守卫；一灯、郭靖和黄蓉的核心事件由其自身推进。主线失败时由朱子柳等 NPC 收束战斗，开启瑛姑与周伯通传闻。

## DL-03：武三通旧怨

链条：疯徒 → 旧情 → 千里江南（任务休眠）→ 陆家杀记 → 赤练仙子 → 疯徒再现。

这是跨区任务样板。大理阶段给出嘉兴陆家庄标记；玩家可任意时间抵达嘉兴继续。面对李莫愁时，目标是坚持、救援或开路，不是击败；结果影响旁支 NPC、毒伤与武三通好感。

## 普通支线模板

大理普通支线使用低复杂度事件：抓闪电貂、采无量茶、采毒草、追回药篓、失踪羊、山中毒蛇、无量弟子的剑、试剑石、东西宗争执、剑湖送信；以及山贼、镖师、商人、山洪、断桥、赌局、客栈、王府、商队、药铺、万劫谷与四大恶人传闻等事件。

每个支线必须记录成功结果和一个可理解的负面结果，例如中毒、受伤、钱财损失、好感下降、声望变化或未来危险标记。
