## 任务树连接

- DL-01 结束开放万劫谷传闻；DL-02 结束开放瑛姑/周伯通旧事；DL-03 在嘉兴进入休眠并继续。
- YN-01 的金蛇旧物传闻连接碧血剑历史线。
- JX-01 开放郭家后人与杨家后人传闻。
- SZ-01 开放还施水阁传闻；HZ-01 与任我行状态关联；WX-01 根据毒抗进入潜行营救或监牢路线。
- YZ-01 结束后韦小宝进入动态 NPC 状态；FZ-01 结束后开放华山、林氏旧宅和辟邪剑谱传闻。

## 实现优先级

1. DL-01《无量山风波》作为任务数据、软失败、前置链和 NPC 好感的样板。
2. YZ-01、JX-01 作为江南新手与区域事件样板。
3. DL-02、SZ-01、HZ-01、WX-01 测试“低等级可旁观、高等级可介入”的高危 NPC 规则。
4. DL-03 验证跨区休眠、恢复与关系持续化。
