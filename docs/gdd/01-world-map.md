# 世界地图 GDD

## 世界结构

世界由“五大朝廷 + 三大缓冲区 + 四大江湖边疆 + 海外”组成。中原、关中、荆襄不可被任何单一政权完全控制。

| 一级区 | 性质 | 节点 | 设计定位 |
|---|---|---|---|
| 江南东南·大宋 | 宋 | 临安、扬州、苏州、嘉兴、福州 | 新手至中期核心，城市和江湖势力最密集 |
| 荆襄 | 宋明前线 | 襄阳、江陵、武昌、汉水、武当 | 战争、守城、传信、救援 |
| 中原 | 多方争夺 | 洛阳、开封、嵩山、少林 | 天下武林中心 |
| 河朔燕云 | 大辽 | 燕京、幽州、大同、雁门关 | 汉辽身份与边军冲突 |
| 塞北草原 | 诸部/辽影响 | 张家口、王庭、蒙古诸营 | 骑射、部族、草原战争 |
| 辽东大金 | 金 | 上京、辽阳、沈州、长白 | 女真旧国与军事体系 |
| 白山黑水 | 满清 | 盛京、赫图阿拉、宁古塔 | 谍报、流放与新兴政权 |
| 西北西夏 | 西夏 | 兴庆府、河西、贺兰山 | 商路、情报、奇门武学 |
| 关中秦地 | 军事缓冲 | 长安、华山、终南、潼关 | 天下交通与百年武学遗迹 |
| 巴蜀西南 | 明势力圈 | 成都、峨眉、青城、剑门 | 山地门派江湖 |
| 云贵大明 | 明 | 昆明、贵阳、云南府 | 明廷遗绪与西南贸易 |
| 大理诸国 | 独立/明属关系 | 大理、无量山、万劫谷、点苍 | 段氏、佛门、异域武学 |
| 东海海外 | 无统一政权 | 桃花、侠客、神龙、灵蛇、台湾 | 海洋开放世界与高阶奇遇 |

## 政治规则

- 辽为高度汉化但保留草原传统的强国，不能被写成单一反派。
- 金与满清严格分立；前者为老牌女真帝国，后者为分裂出的新兴强权。
- 东海是完整海洋开放世界，而非数个一次性副本。
- 每个 NPC 至少需要区域、活动国家、江湖阵营、朝廷关系、政治倾向、声望、危险度与命运阶段字段。
