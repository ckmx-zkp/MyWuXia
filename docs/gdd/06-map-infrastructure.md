# 地图基础设施：两层结构与四类母版规范

本文件规定了《江湖长夜》全部区域、城镇、门派与野外地图的通用基础设施层架构。所有地图策划、任务配置与程序数据结构必须遵循此规范。

---

## 核心设计理念：两层结构与活态江湖

地图不得设计为“仅服务原著剧情的单薄地点”，而必须是由两层构成的生活化江湖舞台：

> **通用生活区域（基础设施层） + 金庸原著特色区域（传奇事件层）**

玩家即使完全不接触原著主线，也可以在城镇内进行住宿、买药、修武器、饮酒餐饮、切磋练功、打听消息、接押镖银、赌博娱乐以及贩卖战利品。

---

## 一、四大地图母版体系

为了控制开发成本并保持玩法规范统一，游戏全域划分为四种标准化地图母版：

| 母版类型 | 节点规模 | 典型场景 | 核心功能定位 |
|---|---|---|---|
| **① 大城市母版** | 15～20 个公共区域 | 扬州、苏州、杭州、洛阳、大理、襄阳、开封、成都、盛京、燕京等 | 江湖综合中心：商业、政权、信息、医疗、交通枢纽 |
| **② 城镇/村庄母版** | 6～10 个节点 | 牛家村、陆家庄附近村落、风陵渡镇、张家口集市、无量山村落 | 基础补给点：民居、民宿、土郎中、农田、村外偶遇 |
| **③ 门派/山庄母版** | 5～12 个节点 | 少林寺、武当山、华山派、峨眉派、参合庄、活死人墓 | 武学研习、门派切磋、内务考验、后山秘境（无衙门/赌场/青楼） |
| **④ 野外/秘境母版** | 探索型网状节点 | 无量山、黑风双煞大漠、长白山雪岭、太湖水域、贺兰山峡谷 | 生态探索、药材矿石采集、遭遇战斗、奇遇秘穴、劫道伏击 |

## 二、大型城市母版统一配置（17项基础公共设施）

大型城市固定包含以下公共场所骨架：

| 设施地点 | 基础功能 | 可产生的游戏机制与内容 |
|---|---|---|
| **01 城门** | 进出城、盘查通缉 | 官兵盘查、逃犯通缉令、过境商队、流民入城事件 |
| **02 客栈** | 住宿、回血、存档、消息 | **城市核心信息中心**：江湖传闻、偶遇各路高手、夜间住店奇遇、偷听机密 |
| **03 酒楼/茶馆** | 饮水进食、状态恢复 | 说书人听书、名士偶遇、情报交换、江湖斗殴、拼酒比试 |
| **04 杂货铺** | 探险日用品与工具出售 | 火折子、绳索、铁铲、捕兽夹、干粮、酒壶、地图等任务核心探索工具 |
| **05 铁匠铺** | 装备买卖、兵器修理、打造 | 购买凡铁精钢武器；武器耐久修复；消耗特殊矿石打造高阶装备 |
| **06 药铺** | 药品购买、解毒疗伤、医术 | 采购金创药/止血散/解毒丸；采药与医术支线；悬壶济世任务 |
| **07 武馆** | 基础武学研习、木人切磋 | **低等级升级保险机制**：切磋无死亡惩罚（输仅扣至1血），供新老侠客稳定磨砺 |
| **08 镖局** | 押镖护送、武师委派 | **核心循环任务体系**：短/中/长途跨城护镖，触发山贼、水匪、黑店、恶劣天气与仇家截镖 |
| **09 钱庄** | 钱币兑换、银票存取 | 携带大额资产凭证；触发劫案、护送银票任务 |
| **10 衙门** | 官府缉盗、功名体制 | 朝廷阵营入口：抓逃犯、查命案、缉盗巡街，积累朝廷功勋与捕快官阶 |
| **11 市场** | 散商摆摊、材料收购 | 偶遇稀有古董商人、辨识假药假货、扒手事件、材料物价浮动 |
| **12 民居区** | 市井百姓生活 | 密集的江湖生活日常支线、邻里纠纷、寻人报恩 |
| **13 寺庙/道观** | 上香祈福、静心休整 | 恢复心境与精神；佛道修持支线；隐世老僧/道长指点（区分于名门大派） |
| **14 赌场** | 掷骰牌九、下注博弈 | 银两博弈、识破老千、赌债纠纷、暗门高利贷支线 |
| **15 青楼/乐坊** | 舞乐品茗、琴棋书画 | 提升雅趣与琴艺；结识名妓佳人；打听权贵官府隐秘内线情报 |
| **16 码头/驿站** | 交通接驳、长途迁跃 | 雇佣快马、车队、漕运大船；快速穿越各大区大城 |
| **17 城郊** | 浅层野外过渡区 | 低阶山贼、流寇、野兽出没；常规草药采摘与矿石挖掘 |

## 三、核心设施机制深度定义

### 1. 客栈：城市第一情报中心与动态偶遇
- **机制原理**：任务目标不应单靠系统菜单直接点出，而应通过客栈听取流言。
  - 例：扬州客栈听闻“京城来了位提督大人”，解锁【京城密信】；苏州客栈听闻“太湖深处有神秘慕容氏”，解锁【燕子坞传闻】；嘉兴客栈听闻“醉仙楼来了几位怪客”，解锁【江南七怪线索】。
- **随机 NPC 驻留池**：
  - 平常为市井茶客、过路镖师、落魄书生。
  - 特定时辰或世界阶段，原著人物（如乔峰、包不同、令狐冲、韦小宝）随机现身于酒座，玩家可与之交谈、敬酒、切磋甚至结为莫逆。

### 2. 杂货铺：玩法道具赋能器
杂货铺不仅出售补给品，而且出售影响玩法成功率的专用工具：
- 绳索与铁铲：攀爬悬崖、挖掘藏宝图遗迹必备。
- 捕兽夹与肉干：如大理捕获闪电貂任务，使用捕兽夹可使成功率 +15%，辅以肉干诱捕可避免被咬伤中毒；未携带者只能徒手承担高失败率与中毒风险。
- 火折子与蜡烛：夜探秘窟、进入古墓必备光源，否则视野受限无法触发暗门。

### 3. 铁匠铺：打造与神兵边界
- 提供常规兵器打造与耐久修理（铁剑、钢刀、长枪、短刃、暗器）。
- 支持玄铁、寒铁、天外陨铁、精钢等稀有矿石的熔炼强化。
- **神兵红线**：倚天剑、屠龙刀、玄铁重剑、金蛇剑等天下至宝**严禁由铁匠铺打造**，必须通过专属原著史诗任务、秘境探索或机缘获取。

### 4. 镖局：全域循环经济与历练系统
- 提供星级跨城护镖任务（扬州→苏州 ★；苏州→杭州 ★★；洛阳→襄阳 ★★★；大理→成都 ★★★★；西夏→中原 ★★★★★）。
- 沿途动态随机遭遇事件池：山林响马、水运飞盗、荒郊黑店、官兵苛扣盘查、恶劣雨雪阻路、仇家寻仇、隐世高手劫镖。

## 五、城市策划标准数据结构（城市模板规范）

```text

A. 公共城区（固定 17 项基础设施 + 对应风貌特称）
   01 城门 / 02 客栈 / 03 酒楼茶馆 / 04 市场 / 05 杂货铺
   06 药铺 / 07 铁匠铺 / 08 武馆 / 09 镖局 / 10 钱庄
   11 衙门 / 12 民居 / 13 寺庙道观 / 14 赌场 / 15 青楼乐坊

B. 原著特色区域（专属原著地理地标，如燕子坞、醉仙楼、参合庄、丽春院、陆家庄）

C. NPC 动态池（常驻生活 NPC + 原著游历人物的出现条件与境界）
```
