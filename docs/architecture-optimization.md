# 江湖长夜 · 架构现状与后续

> 2026-09-07：P0-A/B/C 已接入。当前 v7 存档；旧任务树与三帮命运保留适配，批量迁移属于 P1。

## 当前执行链

UI → `commands.js` → 世界查询 / 条件 / 原子效果 → 事件或模拟结算 → 经历与存档 → 界面回响。

- `world-rules.js`：显式命名空间查询、all/any/not、比较、条件对白、原子成本及效果。未知条件/效果报错。
- `side-events.js`：节点、选项、后继、战斗 pending、选择记录及结算凭据。同一节点选项的效果只发一次；修补等再次尝试仍需支付配置成本。
- `p0-engine.js`：房间、持续活动、教学与装备；护药、武当考核、江南密信和药路回信使用同一事件契约。
- `world-engine.js`：保留旧任务/旅途/循环战斗结算适配；命令即时调用，不再创建新的现实等待。
- `fate-engine.js`：世界秒推进，跨越期限时逐个处理边界；离线活动不推进命运。
- `city-leads.js`：从真实进度派生本地任务、人物线、支线去向与邻接路线，不另存一份任务完成状态。
- `platform/browser.js`：浏览器存储、时钟、前后台通知、导出与音频依赖。
- `services/audio-manager.js`：每个 App 独立音频实例，统一淡化、对白压低背景音乐、队列及重开/读档/卸载清理。

## 世界事实契约

`fact:` → p0.facts，`world:` → flag，`npc:` → p0.npcs，`character:` → npcStates。资源、门派、关系、武学心得、基本功、区域与房间都有明确查询入口。命名空间不隐式合并，避免同名事实冲突；当前不复制旧字段到第二套状态。

成本与效果先校验，使用不可变状态结算；异常不会污染输入状态。旧剧情 effects.js 和三帮结构继续作为兼容实现，后续逐棵迁移，不双写新旧事实。

## 存档与时间

v7 接受 v1-v6。旧 travel/quest/routine/spar 记录通过加载命令按剩余游戏时间续接一次；进行中战斗保持原种子和回合。新事件保存内容版本、节点、pending、选择和效果凭据，旧事件缺这些扩展字段时继续兼容。

旅行十个世界秒；旧一次性任务沿用配置的世界秒；事件抉择两秒、房间移动一秒；可见页面心跳继续推进一秒和战斗一回合。持续活动使用独立墙钟，离线最多八小时。即时行动额外消耗游戏时间，不伪装成网络加载。

## 工程门槛

`npm test` → `npm run build`（含内容校验）→ 桌面/手机路径验证 → `npm run deploy`（再次测试并构建）→ 线上验证 → Git 提交与推送。

索引检查兼容 CRLF，生成文件固定 LF。剧情仍按区域分包。新增核心结算必须具备失败、重复调用和旧档恢复测试。
